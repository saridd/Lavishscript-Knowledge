# Debugging
 
Preferred format:
 
```lavishscript
echo "DEBUG: Message"
```
 
Examples:
 
```lavishscript
echo "DEBUG: LootResolve=${LootResolve}"
```
 
```lavishscript
echo "DEBUG: BestPlayer=${BestPlayer}"
```
 
```lavishscript
echo "DEBUG: ReceivedPlayerCount=${ReceivedPlayerCount}"
```
 
## Debug Strategy
 
1. Verify entry.
2. Verify inputs.
3. Verify decisions.
4. Verify outputs.
5. Verify side effects.
